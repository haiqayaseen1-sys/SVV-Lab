# Delivery Robot Requirements

## Task 1 — Extract Requirements

| Req. ID | Requirement |
|---|---|
| R1 | The robot shall remain in **IDLE** state when no delivery request is received. |
| R2 | The robot shall start **NAVIGATING** when a delivery request is received. |
| R3 | The robot shall continuously monitor its surroundings while navigating. |
| R4 | The robot shall enter **AVOIDING_OBSTACLE** when an obstacle is detected. |
| R5 | The robot shall resume **NAVIGATING** after successfully avoiding an obstacle. |
| R6 | The robot shall enter **DELIVERING** when it reaches the destination. |
| R7 | The robot shall enter **RETURNING** after successfully delivering the package. |
| R8 | The robot shall continuously monitor its battery level during navigation. |
| R9 | The robot shall enter **RETURNING** when its battery becomes critically low. |
| R10 | The robot shall become **IDLE** after reaching the warehouse. |
